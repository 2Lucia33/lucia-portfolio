# 片场失控｜游戏策划作品集 Demo

一个无需构建工具的轻量网页游戏。玩家担任电影《最后一次告别》的现场导演，在三场戏中做出 15 次决策。项目含 24 个片场事件，每场随机抽取 5 个；所有选项都显示即时数值反馈，结尾给出评分、导演风格与关键决策回顾。

## 本地运行

直接双击 `index.html` 即可在浏览器运行。也可在本目录启动本地服务：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。没有第三方依赖，也不需要注册账号。

## 策划规则

- 四项数值均为 0–100：时间、预算、演员状态、成片质量。
- 第一场从 100 时间与 100 预算开始；进入第二场补充 55 时间与 35 预算，第三场补充 50 时间与 30 预算，每项上限 100。
- 每个事件有 3 个选择，都会改变数值。资源为 0 时仍可继续，结算会体现资源不足的代价。
- 最终评分 = 成片质量 × 55% + 演员表现 × 25% + 资源控制 × 20%；资源控制是剩余时间与预算的平均值。
- 导演风格由四类决策标签（演员、视觉、叙事、执行）中选择次数最多的一类决定。
- 随机性只影响抽取的事件及其顺序；相同选择的数值结果固定，便于玩家理解因果。

## 作品集集成

本 Demo 位于作品集的 `games/filmset-chaos/` 目录。首页包含项目介绍与体验入口，游戏页顶部可返回作品集。

在仓库根目录运行 `python3 -m http.server 8000`，访问 `http://localhost:8000/games/filmset-chaos/index.html`。部署时保留整个仓库结构，游戏随作品集一起发布；所有资源与返回链接均使用相对路径。
