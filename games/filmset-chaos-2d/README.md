# 片场失控 · 2D 片场原型

第一场「重逢」的独立可玩原型。保留原文字版，首页主要体验入口指向本版，并提供文字版链接。

在仓库根目录运行 `python3 -m http.server 8000`，访问 `http://localhost:8000/games/filmset-chaos-2d/`。也可直接打开本目录的 `index.html`；没有构建步骤或外部依赖。

## 操作与循环

- 电脑：点击片场使其获得键盘焦点，WASD / 方向键移动，E / 空格互动。
- 手机或鼠标：点击地面走动，点击人物或灯光台自动走近互动。滑动页面不会触发移动。
- 片场清单提供不依赖画布的交互入口，键盘也可操作；弹窗支持 Escape 返回（开场与结果除外）。
- 五个固定事件可任意顺序处理，每件事只能选择一次。选择后显示实际数值变化，并改变场景表现。
- 全部完成后，点击「开始拍摄」或靠近摄影机互动，观看约七秒的片场演出，再查看单场评分及导演风格。
- 走动不扣资源；时间和预算只因决定改变，四项数值限制在 0–100。评分沿用文字版公式，但为单场结果。
- 可暂停；切到其他标签页会自动暂停。结算后可以重玩或回看片场。本版不持久保存进度。

## 文件

- `index.html` / `styles.css`：页面、响应式布局、通告清单、无障碍弹窗。
- `engine.js`：五个事件、数值规则、评分与网格寻路，可独立测试。
- `app.js`：Canvas 纸片场景、移动与交互、拍摄演出。所有图形由代码绘制，无第三方图片、字体、音频或网络请求。
- `check.cjs`：规则、重复选择保护、所有选项和寻路可达性检查。运行 `node check.cjs`。

## 原型边界

目前只有一场、五个固定事件；无音效、存档、独立操作小游戏或复杂角色 AI。美术为代码绘制的临时纸片形状。后续可替换正式素材并扩展场景，先验证走动—互动—决定—演出循环。

随作品集通过 GitHub Pages 发布，使用相对资源路径，支持仓库子目录。
